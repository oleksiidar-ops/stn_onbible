# Путь от А до Я

Презентация проекта «Сложных текстов нет» и платформы OnBible (RU/EN).

- На компьютере — слайды 16:9: стрелки, пробел, колесо мыши, свайп.
- На телефоне и в вертикальной ориентации — одна прокручиваемая страница.
- Язык: по умолчанию английский, кнопки RU/EN или ссылка с `#en` / `#ru`. Конкретный слайд: `#s5`.

## Фото

Положите файл в папку `img/` с именем слота — он сам встанет вместо заглушки. Подходят `.jpg`, `.png`, `.webp`.
